# לוח שיעורים — מתמטיקה ופיזיקה

לוח דיגיטלי לשיעורים פרטיים, שמשלב:
- **ציור וסימון** (כמו "צייר"), עם צורות מדויקות והצמדה לרשת
- **משוואות** בסגנון LaTeX, עם עורך נוח כמו ב-Word
- **פסקאות** בעברית עם נוסחאות בתוך הטקסט: הגדרות, משפטים והוכחות
- **ספרייה** של הגדרות ומשפטים לאלגברה לינארית 1+2 ולחדו"א 1
- **גרפים** של Desmos בתוך הלוח עצמו, כולל מצב מסך מלא

כל שיעור הוא מחברת עם כמה עמודים. כל שינוי נשמר אוטומטית בדפדפן.

---

## הפעלה

**הדרך הקלה:** לחיצה כפולה על `start.bat`. בפעם הראשונה ההתקנה לוקחת דקה או שתיים. הדפדפן ייפתח לבד בכתובת http://localhost:5173.

**משורת הפקודה:**
```bash
npm install      # פעם אחת בלבד
npm run dev      # מפעיל את האתר בכתובת http://localhost:5173
```

> צריך שיהיה מותקן [Node.js](https://nodejs.org) (גרסה 20 ומעלה).
> הגרפים של Desmos והפתרון המהיר נטענים מהאינטרנט. בלי חיבור לאינטרנט, הציור, המשוואות והפסקאות עובדים, אבל הגרפים לא.

## העלאה לאינטרנט (Vercel) והתקנה כאפליקציה

### העלאה, פעם ראשונה ובכל עדכון
בתיקיית הפרויקט מריצים:
```bash
npm run deploy
```
- **בפעם הראשונה** נפתח דפדפן להתחברות לחשבון Vercel (אפשר עם GitHub, Google או מייל). אחרי ההתחברות חוזרים לטרמינל.
- בסוף מופיעה כתובת קבועה, למשל `https://mathlessons.vercel.app`. אפשר לפתוח אותה מכל מחשב.
- **בכל עדכון** מריצים שוב את אותה פקודה. הכתובת נשארת אותה כתובת.

### התקנה כתוכנה במחשב
- פותחים את הכתובת ב-Chrome או ב-Edge ולוחצים על "💻 התקן כאפליקציה" בספרייה, או על אייקון ההתקנה בשורת הכתובת.
- האפליקציה נפתחת בחלון משלה, עם אייקון בתפריט התחל.
- ציור ומשוואות עובדים גם בלי אינטרנט. גרפים ופתרון מהיר צריכים חיבור.

### ⚠️ העברת שיעורים בין כתובות
השיעורים שמורים בנפרד לכל כתובת: `localhost:5173` והאתר באינטרנט הם שני מקומות שונים. כדי להעביר שיעורים:
1. בכתובת הישנה לוחצים "⬇ גיבוי".
2. בכתובת החדשה לוחצים "⬆ שחזור" ובוחרים את הקובץ.

### ‏Desmos
הגרפים של Desmos משתמשים במפתח API המובנה באפליקציה. כדי להשתמש במפתח אחר (מקבלים בחינם ב-https://www.desmos.com/my-api), מדביקים אותו בכפתור "⚙ Desmos" בספריית השיעורים.

### כלים של הלוח (Excalidraw)
‏`R` מלבן · `O` עיגול · `D` מעוין · `A` חץ · `L` קו · `T` טקסט · `E` מחק · `H` הזזת הלוח · `Ctrl+Z` ביטול · `Ctrl+'` הצגה או הסתרה של הרשת

אפשר לגלול עם גלגלת העכבר, ולעשות זום עם `Ctrl` + גלגלת.

### עורך המשוואות
כדי לפתוח: הכפתור הכחול "∑ משוואה" בסרגל העליון, או `M` או `Alt+=`. בעמוד ריק מופיע גם קיצור דרך באמצע הלוח.

יש שתי דרכים לכתוב, והן מסונכרנות:
- **בשדה הוויזואלי** (כמו ב-Word) מקלידים בצורה טבעית:
  - `/` יוצר שבר
  - `^` יוצר חזקה
  - `_` יוצר אינדקס
  - ‏`sqrt` יוצר שורש
  - ‏`pi`, `alpha`, `int`, `lim`, `sum`, `infty` יוצרים את הסימן המתאים
  - `<=` ו-`>=` יוצרים ≤ ו-≥
- **בתיבת "קוד LaTeX"** מתחת לשדה הוויזואלי אפשר להקליד או להדביק LaTeX רגיל, למשל `\int_0^2 (x^2-4)\,dx`. השדה הוויזואלי מתעדכן תוך כדי הקלדה. `Ctrl+Enter` מוסיף ללוח.
- הכפתורים בחלק העליון של העורך מוסיפים תבניות מוכנות, בארבע לשוניות: **בסיסי** (שבר, חזקה, שורש, מערכת משוואות), **חדו"א** (גבולות חד-צדדיים, אינטגרלים, טורים, טיילור), **אלגברה לינארית** (מטריצה בגודל לבחירה, דטרמיננטה, שחלוף, הופכית, נורמה, מכפלה פנימית) ו**קבוצות ולוגיקה** (∀, ∃, ∈, ℝ, ℕ…).
- בשדה הוויזואלי יש קיצורים נוספים שהופכים לסימן תוך כדי הקלדה: `eps`, `forall`, `exists`, `RR`, `NN`, `det`, `rank`, `ker`, `norm`, `binom`, `pmat` (מטריצה 2×2) ועוד.
- בתיבת הקוד, הקלדת `/` פותחת **תפריט פקודות**: `/matrix` (עם בחירת שורות × עמודות), `/lim`, `/sum`, `/forall`, `/alpha` ועוד. חיצים לבחירה, Enter להכנסה.
- הכפתור "מקלדת מתמטית" פותח מקלדת על המסך עם כל הסימנים.
- אפשר לבחור גודל וצבע. `Enter` מוסיף את המשוואה ללוח.
- **כדי לערוך משוואה קיימת:** לוחצים עליה לחיצה כפולה, או מסמנים אותה ולוחצים `Enter` או "ערוך משוואה".
- טקסט בעברית עם נוסחאות בתוכו כותבים ב**פסקה** (¶, ראו בהמשך). לטקסט קצר בלי נוסחאות אפשר גם תיבת טקסט רגילה (`T`).
- **פתרון בשלבים, שורה אחרי שורה:** כשמשוואה מסומנת על הלוח, המשוואה החדשה נוספת בשורה שמתחתיה.

### פסקאות (הגדרות, משפטים והוכחות)
הכפתור "¶ פסקה" (או `Alt+T`) פותח עורך לטקסט בעברית שנוסחאות משולבות בו, כמו ב-Word:
- כותבים עברית רגילה. נוסחה בתוך השורה נכתבת בין סימני דולר: `לכל $\varepsilon>0$ קיים $\delta>0$`. נוסחה בשורה נפרדת ובמרכז: `$$…$$`.
- עיצוב: `**מודגש**`, שורה שמתחילה ב-`- ` היא תבליט, `1. ` מספור, `# ` כותרת. שורה ריקה מתחילה פסקה חדשה.
- הקלדת `/` פותחת תפריט פקודות: `/def` ו-`/thm` מוסיפים "**הגדרה.**" ו"**משפט.**", `/proof` מוסיף שלד הוכחה, `/eps-delta` את הגדרת הגבול, `/induction` שלד אינדוקציה, `/alpha`, `/forall`, `/RR` סימנים, ו-`/lim`, `/sum`, `/matrix` נוסחאות.
- מימין רואים תצוגה מקדימה חיה, בדיוק כפי שהפסקה תיראה על הלוח. בוחרים גודל, צבע ורוחב (480 עד 1000 פיקסלים). `Ctrl+Enter` מוסיף ללוח.
- על הלוח הפסקה מתנהגת כמו משוואה: אפשר להזיז, לשנות גודל, ולערוך בלחיצה כפולה או ב-`Enter`. פסקה חדשה נכנסת מתחת לאלמנט המסומן, מיושרת לימין.

### ספרייה (📚)
הכפתור "📚 ספרייה" (או `Alt+L`) פותח אוסף של הגדרות, משפטים ותבניות תרגיל, מסודר לפי קורס: **אלגברה לינארית 1**, **אלגברה לינארית 2** ו**חדו"א 1**, ובתוך כל קורס לפי נושא.
- בוחרים קטע ורואים אותו בתצוגה מקדימה. "הוסף ללוח" מכניס אותו מתחת לאלמנט המסומן; "פתח בעורך" טוען אותו לעורך כדי לשנות לפני ההוספה. לחיצה כפולה מוסיפה ישירות.
- תיבת החיפוש מחפשת בכל הקורסים יחד.
- **קטעים משלך:** מסמנים פסקה או משוואה על הלוח ולוחצים "☆ שמור כקטע". נותנים כותרת, קורס ותת-נושא. הקטעים האישיים נשמרים בדפדפן ונכללים בקובץ הגיבוי, ואפשר למחוק אותם מהספרייה (🗑).
- התוכן המובנה נכתב לפי הסילבוס הסטנדרטי. כדאי לעבור עליו ולהתאים לניסוח שלך.

### פתרון מהיר (תשובה סופית)
בעורך המשוואות, מתחת לתיבת הקוד, יש שורות כפתורים: **כללי** (פתור · גזור · אינטגרל · גבול · פשט · פרק לגורמים · פתח סוגריים), **טורים וטיילור** (סכום טור · פולינום טיילור), וכשכותבים מטריצה או `\det` גם **אלגברה לינארית** (דטרמיננטה · הופכית · דרגה · דירוג RREF · ערכים עצמיים · וקטורים עצמיים · שחלוף).
- כותבים את הביטוי ולוחצים על הפעולה. התשובה מחושבת במנוע של GeoGebra ומוצגת מתחת לכפתורים.
- **פתור:**
  - עובד על משוואה, אי-שוויון, או מערכת משוואות (התבנית `{ }`).
  - ביטוי בלי `=` נפתר כאילו נכתב `= 0`.
  - אם אין פתרון מדויק, מוצג פתרון מקורב. אם אין פתרון ממשי, מופיעה הודעה.
- **גזור ואינטגרל** עובדים גם על הגדרה כמו `f(x)=x^3`. התוצאה במקרה הזה היא `f'(x)=…`.
- **אינטגרל:** משאירים את הגבולות ריקים לאינטגרל לא מסוים, או ממלאים "מ-" ו"עד" לאינטגרל מסוים.
- **גבול:** בוחרים לאיזה ערך המשתנה שואף, כולל ∞ ו-∞-, ואפשר לבחור גבול מימין או משמאל.
- **מטריצות:** כותבים מטריצה בעורך (לשונית "אלגברה לינארית" או `/matrix`) ובוחרים את הפעולה. התשובה מוצגת כמטריצה.
- **טור:** כותבים את האיבר הכללי (או ביטוי שלם כמו `\sum_{n=1}^{\infty} \frac{1}{n^2}`) ומקבלים את הסכום, ואם אין סכום מדויק, ערך מספרי.
- **טיילור:** בוחרים נקודת פיתוח ודרגה ומקבלים את הפולינום.
- **אחרי שהתשובה מופיעה:**
  - "הוסף ללוח" מוסיף שורה שלמה, למשל `∫ (x²-4) dx = x³/3 - 4x + C`.
  - "העבר לעורך" מעביר את השורה לעורך, כדי לערוך אותה לפני ההוספה.
- הפעם הראשונה בכל פתיחה של האפליקציה לוקחת כמה שניות, כי המנוע נטען. צריך חיבור לאינטרנט.
- ⚠️ בשיתוף מסך, התלמיד רואה את חלון העורך, ולכן גם את התשובה.

### גרף Desmos
- לחיצה על "גרף ▾" פותחת בחירה בין **גרף דו-ממדי** לבין **גרף תלת-ממדי**, למשל משטחים כמו `z=x^2-y^2`, ישרים ומישורים במרחב. בחירה מוסיפה חלון Desmos שממלא כמעט את כל המסך. אפשר להזיז אותו (מהפס האפור העליון) ולשנות את הגודל שלו (לוחצים על הפס ואז גוררים מהפינות) כמו כל צורה אחרת.
- **מסך מלא:** הכפתור "⛶ מסך מלא" בפס העליון של הגרף פותח אותו על כל החלון, נוח לעבודה ממושכת בשיתוף מסך. `Esc` (או "חזרה ללוח") חוזר ללוח, והגרף הקטן מתעדכן עם כל מה שנעשה.
- הגרף אינטראקטיבי תמיד: העכבר בתוך החלון פועל ישירות על Desmos.
- לוחות ישנים עם גרפי GeoGebra עדיין נפתחים ועובדים, אבל גרפים חדשים הם תמיד Desmos.
- בשורת הקלט אפשר להקליד פונקציות (`f(x)=x^2-4`), נקודות (`A=(2,0)`) ופקודות כמו `Solve(x^2-4=0)`, `Derivative(f)`, `Integral(f,0,2)`.
- הגרף נשמר עם השיעור, כולל הזום והמיקום.
- **גודל הכתב בתוך הגרף:**
  - הכפתורים **A− / A+** בפס העליון של הגרף מגדילים או מקטינים את המשוואות, הצירים והמספרים, בין 80% ל-200%. זה שימושי במיוחד בשיתוף מסך.
  - הכתב בתוך הגרף נשאר באותו גודל גם כשמקטינים או מגדילים את הלוח.

### עמודים
הפאנל בצד ימין מציג את העמודים של השיעור. אפשר להוסיף עמוד, לשכפל, למחוק ולשנות את הסדר.

### ייצוא ל-PDF
- הכפתור "⬇ PDF" בסרגל העליון של השיעור, או הכפתור "PDF" בכרטיס השיעור בספרייה, יוצר קובץ PDF.
- כל עמוד בשיעור נהיה עמוד A4 בקובץ. עמודים ריקים מדולגים.
- גרפים מופיעים בקובץ כתמונה של המצב האחרון שלהם, בלי חלון האלגברה.
- בתחתית כל עמוד מופיעים שם השיעור ומספר העמוד. הקובץ מוכן לשליחה לתלמיד.

### תבניות שיעור
- **שמירת תבנית:** בתוך שיעור לוחצים על "☆ שמור כתבנית". נשמר עותק של השיעור בלי שם התלמיד, והשיעור המקורי לא משתנה.
- **שימוש בתבנית:**
  - בלשונית "תבניות" בספרייה לוחצים על "+ שיעור חדש מהתבנית".
  - או ב"שיעור חדש" בוחרים תבנית ברשימה "התחל מ-".
- **עריכת תבנית:** פותחים אותה מהלשונית "תבניות". שינויים בתבנית לא משפיעים על שיעורים שכבר נוצרו ממנה.

## שמירה וגיבוי ⚠️
- השיעורים נשמרים **בדפדפן הזה בלבד**. אם עוברים לדפדפן אחר או מוחקים את נתוני הגלישה, השיעורים לא יופיעו.
- **בספריית השיעורים, לחצו מדי פעם על "⬇ גיבוי".** הכפתור מוריד קובץ אחד עם כל השיעורים, התבניות והקטעים האישיים מהספרייה. אם עבר שבוע מהגיבוי האחרון, תופיע תזכורת צהובה.
- השיעורים נשמרים לפי כתובת האתר, כולל מספר הפורט, ולכן האפליקציה תמיד רצה בכתובת http://localhost:5173. אם הכתובת תפוסה, סגרו חלון שחור קודם שעדיין פתוח.
- "⬆ שחזור" טוען קובץ גיבוי, גם במחשב אחר.

```bash
npm run build    # בנייה לפרודקשן (התיקייה dist/)
npm run deploy   # העלאה ל-Vercel
```
מבנה הקוד:
- ‏`src/board/` — הלוח, העמודים, השמירה האוטומטית וסרגל הכלים
- ‏`src/math/` — עורך המשוואות (MathLive) והמרת LaTeX ל-SVG (MathJax)
- ‏`src/para/` — פסקאות: פרסר, רינדור ל-SVG, עורך ותפריט הסלאש
- ‏`src/library/` — ספריית ההגדרות והמשפטים (התוכן המובנה ב-`content/`)
- ‏`src/solve/` — הפתרון המהיר (CAS של GeoGebra ב-iframe מוסתר)
- ‏`src/graph/` + `public/desmos.html` — הגרפים של Desmos, כל גרף ב-iframe משלו, ומצב מסך מלא (`public/ggb.html` נשאר ללוחות ישנים)
- ‏`src/storage/db.ts` — שמירה ב-IndexedDB וגיבוי
- ‏`src/home/` — ספריית השיעורים
