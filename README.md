# לוח שיעורים — מתמטיקה, פיזיקה והסתברות

לוח דיגיטלי לשיעורים פרטיים, שמשלב:
- **ציור וסימון** (כמו "צייר"), עם צורות מדויקות והצמדה לרשת
- **משוואות** בסגנון LaTeX, עם עורך נוח כמו ב-Word
- **גרפים** של GeoGebra בתוך הלוח עצמו

כל שיעור הוא מחברת עם כמה עמודים. כל שינוי נשמר אוטומטית בדפדפן.

---

## הפעלה

**הדרך הקלה:** לחיצה כפולה על `start.bat`. בפעם הראשונה ההתקנה לוקחת דקה או שתיים. הדפדפן ייפתח לבד בכתובת http://localhost:5173.

**משורת הפקודה:**
```bash
npm install      # פעם אחת בלבד
npm run dev      # מפעיל את האתר בכתובת http://localhost:5173
```

> צריך שיהיה מותקן [Node.js](https://nodejs.org) (גרסה 20 ומעלה).
> הגרפים של GeoGebra נטענים מהאינטרנט. בלי חיבור לאינטרנט, הציור והמשוואות עובדים, אבל הגרפים לא.

## העלאה לאינטרנט (Vercel) והתקנה כאפליקציה

### העלאה, פעם ראשונה ובכל עדכון
בתיקיית הפרויקט מריצים:
```bash
npm run deploy
```
- **בפעם הראשונה** נפתח דפדפן להתחברות לחשבון Vercel (אפשר עם GitHub, Google או מייל). אחרי ההתחברות חוזרים לטרמינל.
- בסוף מופיעה כתובת קבועה, למשל `https://mathlessons.vercel.app`. אפשר לפתוח אותה מכל מחשב.
- **בכל עדכון** מריצים שוב את אותה פקודה. הכתובת נשארת אותה כתובת.

### התקנה כתוכנה במחשב
- פותחים את הכתובת ב-Chrome או ב-Edge ולוחצים על "💻 התקן כאפליקציה" בספרייה, או על אייקון ההתקנה בשורת הכתובת.
- האפליקציה נפתחת בחלון משלה, עם אייקון בתפריט התחל.
- ציור ומשוואות עובדים גם בלי אינטרנט. גרפים ופתרון מהיר צריכים חיבור.

### ⚠️ העברת שיעורים בין כתובות
השיעורים שמורים בנפרד לכל כתובת: `localhost:5173` והאתר באינטרנט הם שני מקומות שונים. כדי להעביר שיעורים:
1. בכתובת הישנה לוחצים "⬇ גיבוי".
2. בכתובת החדשה לוחצים "⬆ שחזור" ובוחרים את הקובץ.

### ‏Desmos
הגרפים של Desmos משתמשים במפתח ההדגמה של Desmos. לשימוש קבוע מומלץ:
1. לבקש מפתח אישי בחינם ב-https://www.desmos.com/my-api.

## שימוש בזמן שיעור

### כלים בסרגל העליון
| כפתור | קיצור | מה הוא עושה |
|---|---|---|
| ∑ משוואה | ‏`M` או `Alt+=` (כמו ב-Word) | פותח את עורך המשוואות |
| 📈 גרף ▾ | ‏`Alt+G` (דו-ממדי) · `Alt+3` (תלת-ממדי) | מוסיף גרף GeoGebra אינטראקטיבי |
| 🎲 הסתברות | ‏`Alt+P` | עץ הסתברויות, דיאגרמת ון וטבלה דו-ממדית |
| ✏️ עט | ‏`P` | ציור חופשי |
| 🖍️ מרקר | ‏`U` | סימון צהוב שקוף. כשעוברים לכלי אחר, ההגדרות הקודמות חוזרות |
| 🔴 לייזר | ‏`K` | מצביע שנעלם מעצמו, מתאים במיוחד לזום |
| ⛶ מצב הצגה | | מסך מלא בלי תפריטים, לשיתוף מסך. מעבר בין עמודים ב-`PageUp`/`PageDown` |

### כלים של הלוח (Excalidraw)
‏`R` מלבן · `O` עיגול · `D` מעוין · `A` חץ · `L` קו · `T` טקסט · `E` מחק · `H` הזזת הלוח · `Ctrl+Z` ביטול · `Ctrl+'` הצגה או הסתרה של הרשת

אפשר לגלול עם גלגלת העכבר, ולעשות זום עם `Ctrl` + גלגלת.

### עורך המשוואות
כדי לפתוח: הכפתור הכחול "∑ משוואה" בסרגל העליון, או `M` או `Alt+=`. בעמוד ריק מופיע גם קיצור דרך באמצע הלוח.

יש שתי דרכים לכתוב, והן מסונכרנות:
- **בשדה הוויזואלי** (כמו ב-Word) מקלידים בצורה טבעית:
  - `/` יוצר שבר
  - `^` יוצר חזקה
  - `_` יוצר אינדקס
  - ‏`sqrt` יוצר שורש
  - ‏`pi`, `alpha`, `int`, `lim`, `sum`, `infty` יוצרים את הסימן המתאים
  - `<=` ו-`>=` יוצרים ≤ ו-≥
- **בתיבת "קוד LaTeX"** מתחת לשדה הוויזואלי אפשר להקליד או להדביק LaTeX רגיל, למשל `\int_0^2 (x^2-4)\,dx`. השדה הוויזואלי מתעדכן תוך כדי הקלדה. `Ctrl+Enter` מוסיף ללוח.
- הכפתורים בחלק העליון של העורך מוסיפים תבניות מוכנות: שבר, אינטגרל מסוים, גבול, מערכת משוואות, מטריצה ועוד.
- הכפתור "מקלדת מתמטית" פותח מקלדת על המסך עם כל הסימנים.
- אפשר לבחור גודל וצבע. `Enter` מוסיף את המשוואה ללוח.
- **כדי לערוך משוואה קיימת:** לוחצים עליה לחיצה כפולה, או מסמנים אותה ולוחצים `Enter` או "ערוך משוואה".
- טקסט בעברית כותבים בתיבת טקסט נפרדת (`T`) ליד המשוואה.
- **פתרון בשלבים, שורה אחרי שורה:** כשמשוואה מסומנת על הלוח, המשוואה החדשה נוספת בשורה שמתחתיה.

### פתרון מהיר (תשובה סופית)
בעורך המשוואות, מתחת לתיבת הקוד, יש שורת כפתורים: **פתור · גזור · אינטגרל · גבול · פשט · פרק לגורמים · פתח סוגריים**.
- כותבים את הביטוי ולוחצים על הפעולה. התשובה מחושבת במנוע של GeoGebra ומוצגת מתחת לכפתורים.
- **פתור:**
  - עובד על משוואה, אי-שוויון, או מערכת משוואות (התבנית `{ }`).
  - ביטוי בלי `=` נפתר כאילו נכתב `= 0`.
  - אם אין פתרון מדויק, מוצג פתרון מקורב. אם אין פתרון ממשי, מופיעה הודעה.
- **גזור ואינטגרל** עובדים גם על הגדרה כמו `f(x)=x^3`. התוצאה במקרה הזה היא `f'(x)=…`.
- **אינטגרל:** משאירים את הגבולות ריקים לאינטגרל לא מסוים, או ממלאים "מ-" ו"עד" לאינטגרל מסוים.
- **גבול:** בוחרים לאיזה ערך המשתנה שואף, כולל ∞ ו-∞-.
- **אחרי שהתשובה מופיעה:**
  - "הוסף ללוח" מוסיף שורה שלמה, למשל `∫ (x²-4) dx = x³/3 - 4x + C`.
  - "העבר לעורך" מעביר את השורה לעורך, כדי לערוך אותה לפני ההוספה.
- הפעם הראשונה בכל פתיחה של האפליקציה לוקחת כמה שניות, כי המנוע נטען. צריך חיבור לאינטרנט.
- ⚠️ בשיתוף מסך, התלמיד רואה את חלון העורך, ולכן גם את התשובה.

### גרף GeoGebra
- לחיצה על "גרף ▾" פותחת בחירה בין **גרף דו-ממדי** לבין **גרף תלת-ממדי**, למשל משטחים כמו `z=x^2-y^2`, ישרים ומישורים במרחב. בחירה מוסיפה חלון GeoGebra. אפשר להזיז אותו ולשנות את הגודל שלו כמו כל צורה אחרת.
- **כדי לעבוד בתוך הגרף:** לוחצים פעם אחת כדי לסמן את החלון, ואז לוחצים במרכז שלו. כשסיימתם, לוחצים מחוץ לחלון.
- בשורת הקלט אפשר להקליד פונקציות (`f(x)=x^2-4`), נקודות (`A=(2,0)`) ופקודות כמו `Solve(x^2-4=0)`, `Derivative(f)`, `Integral(f,0,2)`.
- הגרף נשמר עם השיעור, כולל הזום והמיקום.
- **גודל הכתב בתוך הגרף:**
  - הכפתורים **A− / A+** בפס העליון של הגרף מגדילים או מקטינים את המשוואות, הצירים והמספרים, בין 80% ל-200%. זה שימושי במיוחד בשיתוף מסך.
  - הכתב בתוך הגרף נשאר באותו גודל גם כשמקטינים או מגדילים את הלוח.

### כלי הסתברות (🎲)
בכל כלי יש תצוגה מקדימה. מה שנוסף ללוח הוא קבוצה אחת: אפשר להזיז אותה בבת אחת, או ללחוץ פעמיים כדי לערוך טקסט בודד.
- **עץ הסתברויות:**
  - 1 עד 3 שלבים, עם שמות הענפים מופרדים בפסיק.
  - בברירת המחדל לכל שלב יש הסתברויות קבועות. אפשר לסמן "הסתברויות שונות לכל צומת" בשביל הסתברות מותנית, למשל הוצאה בלי החזרה.
  - את ההסתברות אפשר לכתוב כ-`1/3`, ‏`0.25`, ‏`40%` או כביטוי כמו `p` או `1-p`.
  - בסוף כל מסלול מוצגת המכפלה, מחושבת במדויק בשברים.
  - אם סכום ההסתברויות בצומת אינו 1, תופיע אזהרה.
  - כיוון העץ: משמאל לימין, מימין לשמאל או מלמעלה למטה.
- **דיאגרמת ון:** 2 או 3 קבוצות, ערך לכל אזור (רק A, ‏A∩B וכו'), ומלבן של מרחב המדגם.
- **טבלה דו-ממדית:** עד 5×5. השורה והעמודה של סה"כ מחושבות לבד כשכל הערכים הם מספרים.

### עמודים
הפאנל בצד ימין מציג את העמודים של השיעור. אפשר להוסיף עמוד, לשכפל, למחוק ולשנות את הסדר.

### ייצוא ל-PDF
- הכפתור "⬇ PDF" בסרגל העליון של השיעור, או הכפתור "PDF" בכרטיס השיעור בספרייה, יוצר קובץ PDF.
- כל עמוד בשיעור נהיה עמוד A4 בקובץ. עמודים ריקים מדולגים.
- גרפים מופיעים בקובץ כתמונה של המצב האחרון שלהם, בלי חלון האלגברה.
- בתחתית כל עמוד מופיעים שם השיעור ומספר העמוד. הקובץ מוכן לשליחה לתלמיד.

### תבניות שיעור
- **שמירת תבנית:** בתוך שיעור לוחצים על "☆ שמור כתבנית". נשמר עותק של השיעור בלי שם התלמיד, והשיעור המקורי לא משתנה.
- **שימוש בתבנית:**
  - בלשונית "תבניות" בספרייה לוחצים על "+ שיעור חדש מהתבנית".
  - או ב"שיעור חדש" בוחרים תבנית ברשימה "התחל מ-".
- **עריכת תבנית:** פותחים אותה מהלשונית "תבניות". שינויים בתבנית לא משפיעים על שיעורים שכבר נוצרו ממנה.

## שמירה וגיבוי ⚠️
- השיעורים נשמרים **בדפדפן הזה בלבד**. אם עוברים לדפדפן אחר או מוחקים את נתוני הגלישה, השיעורים לא יופיעו.
- **בספריית השיעורים, לחצו מדי פעם על "⬇ גיבוי".** הכפתור מוריד קובץ אחד עם כל השיעורים והתבניות. אם עבר שבוע מהגיבוי האחרון, תופיע תזכורת צהובה.
- השיעורים נשמרים לפי כתובת האתר, כולל מספר הפורט, ולכן האפליקציה תמיד רצה בכתובת http://localhost:5173. אם הכתובת תפוסה, סגרו חלון שחור קודם שעדיין פתוח.
- "⬆ שחזור" טוען קובץ גיבוי, גם במחשב אחר.

## למפתחים
```bash
npm test         # בדיקות יחידה
npm run build    # בנייה לפרודקשן (התיקייה dist/)
npm run deploy   # העלאה ל-Vercel
```
מבנה הקוד:
- ‏`src/board/` — הלוח, העמודים, השמירה האוטומטית וסרגל הכלים
- ‏`src/math/` — עורך המשוואות (MathLive) והמרת LaTeX ל-SVG (MathJax)
- ‏`src/graph/` + `public/ggb.html` — הגרפים של GeoGebra, כל גרף ב-iframe משלו
- ‏`src/storage/db.ts` — שמירה ב-IndexedDB וגיבוי
- ‏`src/home/` — ספריית השיעורים
